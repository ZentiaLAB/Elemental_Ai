# Elemental Lab

เกมต่อสู้ด้วย AI รองรับ Pose Project, Image Project และ Audio Project จาก Teachable Machine

## โมเดลที่รองรับ

โมเดลต้องมีคลาสครบและตรงกับชื่อต่อไปนี้เท่านั้น (ไม่สนตัวพิมพ์เล็ก/ใหญ่):

- `Ice` — Frost Lance
- `Fire` — Phoenix Burst
- `Thunder` — Volt Chain
- `Stone` — Terra Fist

ท่าทางของแต่ละ Class ไม่ได้ถูกกำหนดไว้ในโค้ด นักเรียนสามารถออกแบบและฝึกท่าทางเองได้อย่างอิสระ ขอเพียงตั้งชื่อ Class ใน Teachable Machine ให้ตรงกับสี่ชื่อนี้ เกมจะสุ่ม Class ที่ต้องใช้ใหม่ในแต่ละรอบโดยไม่ผูกกับชนิดมอนสเตอร์ และจะไม่สุ่มซ้ำกับ Class ของรอบก่อนหน้า

ใน Teachable Machine สามารถเลือก **Pose Project**, **Image Project** หรือ **Audio Project**, ฝึกทั้งสี่คลาส แล้วเลือก **Export Model → TensorFlow.js → Upload my model** จากนั้นนำ URL โมเดลมาใส่ผ่านปุ่ม **CONNECT MODEL** ในเกม ระบบจะอ่าน `metadata.json` และเลือกกล้องหรือไมโครโฟนให้ตรงกับชนิดโมเดลโดยอัตโนมัติ Audio Project สามารถมีคลาส `Background Noise` ที่ระบบสร้างให้ได้ โดยเกมจะใช้คลาสนี้เพื่อหยุดเสียงรบกวนและจะไม่ปล่อยพลัง

เกมไม่ฝังหรือจดจำ URL โมเดล ผู้เล่นต้องวาง URL จาก Teachable Machine เองทุกครั้งก่อนเชื่อม AI Vision สามารถตรวจไฟล์โมเดลล่วงหน้าได้ด้วย `npm run verify:model -- <MODEL_URL>`

## เปิดเกม

```bash
cd /Users/knight/Development/IOT_Camp/Elemental_Ai
npm install
npm run dev
```

เกมไม่มีปุ่มหรือคีย์ลัดสำหรับร่ายพลัง การ์ดเวทและรายการ Class ใช้แสดงสถานะเท่านั้น พลังจะถูกปล่อยจากผลของ Teachable Machine เมื่อ Class ตรงกับโจทย์และ Confidence อยู่ระหว่าง 95–100% เท่านั้น หากยังไม่มีโมเดลสามารถเปิดกล้องดูภาพได้ แต่จะไม่สามารถโจมตีมอนสเตอร์

เกมจะสุ่มศัตรูจากทั้งสี่ธาตุเมื่อเปิดหน้าและเมื่อกำจัดศัตรูสำเร็จ ช่อง AI Vision แสดงปุ่ม `+` สำหรับเปิด webcam โดยไม่ต้องมีโมเดล เมื่อฝึกโมเดลเสร็จแล้วจึงกด **ADD AI MODEL** เพื่อเปิดการจำแนกท่าอัตโนมัติ

ทุกการร่ายเวทจะแสดงแอนิเมชันโจมตีตามธาตุที่ตรวจพบ พร้อมเอฟเฟกต์กระแทกเมื่อเลือกธาตุถูก และเอฟเฟกต์พลาดเมื่อศัตรูต้านทาน การตั้งค่า `prefers-reduced-motion` ของระบบจะถูกเคารพโดยอัตโนมัติ

ทั้งโหมดกล้องและไมโครโฟน ระบบจะปล่อยพลังเมื่อ Class ที่ตรวจพบตรงกับโจทย์และมี Confidence ตั้งแต่ `95%` ถึง `100%` เท่านั้น หลังปล่อยพลังสำเร็จหนึ่งครั้ง เกมจะสุ่ม Class ถัดไปทันทีโดยไม่ต้องรอให้มอนสเตอร์ถูกกำจัด
